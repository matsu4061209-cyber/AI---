# 運営ジャーナル 自動記入 ― 家のPCでやること

作ったもの（この売上日報フォルダ内）
- `月次自動作成GAS.txt` … 更新済み（Z1の転記用1マスを自動で作る機能を追加）
- `運営ジャーナル記入スクリプト.ts` … 運営ジャーナル側で動かす記入スクリプト

ねらい：**売上日報の1マスをコピー → 運営ジャーナルに貼付 → ボタン1回で記入**
（有料機能・パスワード不要。Edgeで動く）

---

## STEP 0　先に確認（これが無いと自動化は使えない）
運営ジャーナル（PL飯塚の月シート）をEdgeで開き、上のメニューに
**「自動化（Automate）」タブ**があるか見る。
- **ある** → STEP1へ（自動化できる）
- **ない** → 会社が機能を止めている。今まで通り**手入力＋転記カンペ**で運用（下の「カンペ」参照）

---

## STEP 1　売上日報GASを更新（転記用の1マスを作る）
1. 「売上日報月次作成」のGASエディタを開く（仕事用アカウント）
2. コード画面で Ctrl＋A（全選択）
3. `月次自動作成GAS.txt` の中身を全部コピーして貼り付け → 保存
4. 関数一覧から **`addJournalHelperToAllTabs`** を選んで ▶ 実行
   - ログに「OK：31タブにZ1(転記用1マス)を付けました」と出ればOK
   - ※ついでに色そろえがまだなら `applyYumeFormatToAllTabs` も実行

> これで各日のタブの **Z1** に、その日の数値が「|」でつながった文字列ができます。
> 並び：日 | 天候 | 税抜売上 | 客数 | 現金過不足 | UberEats | 出前館 | ゆめ | 8%対象額

---

## STEP 2　記入スクリプトを運営ジャーナルに登録（最初の1回だけ）
1. 運営ジャーナルを開く → **「自動化」タブ → 新しいスクリプト**
2. 出てきたコード画面を全部消す
3. `運営ジャーナル記入スクリプト.ts` の中身を全部コピーして貼り付け
4. 名前を「運営ジャーナル記入」にして保存

---

## STEP 3　毎日の使い方（テスト）
1. 売上日報のその日のタブで、数値を入力
2. **Z1 をコピー**（Ctrl＋C）
3. 運営ジャーナル（PL飯塚の月シート）を開き、**BZ1 に貼り付け**（Ctrl＋V）
4. 「自動化」タブ → **「運営ジャーナル記入」を実行**
5. その日の行（日付＋5行目）に記入される。BZ1は自動で消える

> まず1日分でテスト → 数字が正しい列（D天候/L売上/N客数/P現金過不足/
> AR UberEats/AS 出前館/AO ゆめか/AQ テイクアウト8%）に入るか確認してください。

## 対応表（売上日報 → 運営ジャーナル・データ行＝日付＋5）
| 売上日報 | 運営ジャーナル |
|---|---|
| H6 天気 | D 天候 |
| D9 税抜売上 | L 売上(日計) |
| C37 客数 | N 客数(日計) |
| D35 現金過不足 | P 現金過不足(日計) |
| D19 UberEats | AR |
| D20 出前館 | AS |
| D40 ゆめポイント | AO ゆめか |
| D41 8%対象額 | AQ テイクアウト8% |
| （労働時間 R/S/T） | 後で対応 |

累計・前年・客単価などの自動計算セルには触れません。

例）17日 → 22行目。
